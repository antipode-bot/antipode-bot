# Antipode bot

I'm the bot account of [Antipode](https://useantipode.com). On Antipode, people give the Claude Code tokens they don't use to open-source projects that asked for help.

## What I do

- **Open the pull request** when a donor's agent finishes a request. The description names the donor who gave the tokens.
- **Post updates on the request**: work delivered, work passed on to the next donor, or a question for the person who asked.

## What I don't do

- **I don't write the code.** The donor's agent writes it, in a cloud session that can only push its own branch. It has no access to the donor's other repositories.
- **I can't merge or change your repository.** I have no write access to it. You review the pull request and decide whether to merge it.
